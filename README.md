# پورتفولیو + بلاگ

## نصب و اجرا

```bash
npm install
```

### روش پیشنهادی (دو ترمینال)

ترمینال ۱:
```bash
node server.js
```
باید ببینی: `Server running on http://127.0.0.1:3000`

ترمینال ۲:
```bash
npm run dev:client
```
بعد برو به آدرسی که Vite نشان می‌دهد (معمولاً http://localhost:5173)

### تست سرور
```bash
node test-server.js
```
سپس در مرورگر: http://127.0.0.1:3000
